# V2.1 piirangud

Põhirõhk: ühine kompaktne krundipaigutus, MultiMesh hooned ja synteetiline suur-linna mõõtmine.
See ei too veel üle V131 kogu linna- ja maakonnalaienemise, põllumajanduse ning
riikliku piiriloogika süsteemi. Koormusel 160/100 pole päris 160 tootmis- või
mõttemudelit; lilla kõndija kasutab sama nav adapterit, kuid mitte tööturu
või majapidamise vajaduste simulatsiooni.
