# V1.8 — telefonist ligipääsetav mänguliides

**Oluline:** see on jätkuvalt V131 osaline Godoti katseport, mitte valmis 1:1 mäng.

1. Ava ZIP täiesti uues kaustas ja vali Godot Editoris `project.godot`.
2. Vajuta Play.
3. Maailmakaardi ülaservas on alati nupud **MAAILM**, **LINN**, **LAHING**, **PIIRAMINE**, **MENÜÜ**.
4. **PIIRAMINE** käivitab pronksiaegse katselahingu ning viib kaamera katseareenile.
5. **MENÜÜ** avab vertikaalselt keritava kategooriatega menüü. Valik „Piiramine” sisaldab redelit, piiramistorni, rammi, laagrit ja vallutamise katset.
6. **MAAILM** viib kaamera kogu maailmakaardile tagasi; **LINN** näitab valitud linna lähivaadet.

Võrreldes versiooniga 1.7 eemaldati senine pikk keritav horisontaalne juhtnupurida. Peamine visuaalne probleem kasutaja 23.10.2026 kuvatõmmisel on seega lahendatud lähtekoodis.

Väited Godoti tegeliku käivitumise või juhtnuppude puutetoimimise kohta peavad toetuma päris Godoti jooksutestile.
